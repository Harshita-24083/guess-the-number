Guess the Number 🎯

A simple and interactive Guess the Number game built using HTML, CSS, and JavaScript. The player tries to guess a secret number and receives hints to find the correct answer.

Features

- Generates a secret number for the player to guess.
- Provides hints to help the player.
- Allows the player to enter guesses.
- Displays a message when the correct number is guessed.
- Simple and user-friendly interface.

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the project in your browser.
2. Enter your guessed number in the input field.
3. Click the Guess button to submit your guess.
4. Follow the hints to find the secret number.
5. Keep guessing until you find the correct answer.

Learning Outcomes

- JavaScript conditional statements
- Generating random numbers
- Handling user input
- DOM manipulation
- Using event listeners
